# A day with True Convo (draft)

The whole day, every intended module, the house and build-your-own, as the product is meant to be once finished, for the "A day with True Convo" story page.
Draft only: nothing here is published.

- Open `index.html` in a browser and scroll.
- `vendor/` holds the scroll-craft engine by Nate Herk (MIT, see
  `vendor/scroll-craft-LICENSE.txt`), unchanged. It has no dependencies and
  loads nothing from other sites.
- `fonts/` holds Atkinson Hyperlegible Next (SIL OFL, licence beside it), copied
  from True Convo's brand kit, served from this folder.
- Feature labels ("In testing", "Coming") follow open-convo's STATUS.md as of
  November 1, 2026. Sam and every note and chat shown are invented.
- scroll-craft's paid image generator (kie.ai) is not used.
